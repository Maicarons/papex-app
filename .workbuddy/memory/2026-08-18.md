# papex-app 项目记忆

## 项目概况（2026-08-18 建立）
- 定位：Papex 学术文献平台官方移动端（网页版替代品：读论文/管账号）。独立 GitHub 仓库 Maicarons/papex-app，License Apache-2.0（已拷贝，Copyright 2026 The Papex Authors）。
- 上游：papex 后端（Next.js API + Drizzle + PostgreSQL），消费其 /api 全部端点；类型统一从 openapi.json 生成（scripts/gen-types.sh），禁手写。

## 技术栈（已拍板）
- React Native 0.82（New Architecture 唯一）+ RNOH 0.82.30（鸿蒙适配，2026-05 正式发布）+ TypeScript strict
- React Navigation v7 + Zustand v5 + i18next + react-native-mmkv + react-native-pdf + react-native-keychain（鸿蒙走 HUKS 原生桥，TS 接口统一）
- 推送：FCM(Android)/APNs(iOS)/PushKit(鸿蒙) 三通道统一抽象
- 测试：Jest + RNTL（单测，核心模块覆盖≥80%）+ Detox（iOS/Android E2E）+ 鸿蒙真机手工回归
- 裸 RN 工程（不用 Expo managed）；npm

## 架构与约定
- 目录：src/app(navigators)/src/features(auth|papers|library|messages|profile|settings|push)/src/lib(api|storage|security|push|i18n)/src/components/src/theme/src/stores
- 依赖方向：features 互不 import，跨域走 Zustand store；所有网络请求必须经 lib/api/client.ts（token 注入/401 队列化刷新/429 退避）
- 本地存储：MMKV（app.session.v1、app.sessions.list 多账号≤5、app.paper.{id}.meta、下载索引）+ 沙盒 Documents/papex-pdfs/{paperId}/{version}.pdf（LRU 默认 2GB）

## Tokens 系统（与 desktop 同一契约）
- accessToken JWT HS256 15min（Bearer）；refreshToken 256bit opaque 30d，服务端存 SHA-256 到 devices 表，每次刷新必轮换+设备绑定
- 授权：accessToken 内嵌 perms（papex auth/permissions.ts 打包），客户端仅 UI 显隐，服务端 RBAC 是唯一权威
- 配额：服务端 papex rate-limit（API 120/min、auth 10/min）；客户端 429 指数退避+jitter
- 持久化：iOS Keychain / Android Keystore / 鸿蒙 HUKS（原生桥 secureSet/Get/Delete）；refreshToken 永不进 MMKV/日志

## 后端新增接口（阻塞依赖，需 papex 主仓库排期）
- POST /api/auth/login（App 模式返回 accessToken/refreshToken/deviceId，cookie 行为不变）
- POST /api/auth/refresh（轮换）、POST /api/auth/logout（撤销设备）
- GET/DELETE /api/me/devices(/:id)（设备管理/远程撤销）
- GET/PUT /api/reading-progress/[paperId]
- GET/POST/PUT/DELETE /api/notes（批注云同步，P3 移动端只读）
- POST /api/me/avatar（≤5MB）、POST /api/push/register|unregister
- 新表：devices / reading_progress / notes（DDL 由 papex 仓库落地）

## 功能范围（P0-P3 全实现；admin 不实现）
- P0：认证(登录/注册/多账号/设备管理)、浏览(信息流/257分类)、检索(关键词+语义)、论文详情+PDF在线阅读+进度、收藏、订阅、消息/工单/反馈、个人+背书、设置(语言/主题)
- P1：PDF离线下载+元数据缓存、阅读进度跨端同步、推送、生物识别解锁、API Key管理、三态UI+弱网重试
- P2：评论、背书请求、为你推荐、系统分享、阅读统计
- P3：扫码登录、平板布局、批注只读查看
- 排除：投稿上传、admin/审核/协审、PDF批注编辑
